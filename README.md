# Lukoil

Qt/C++ проект шкафа аварийного освещения с одним измерителем DJSF1352
и последовательным подключением шунтов линий.

- `panel-backend` — управление оборудованием и тестами.
- `panel-hmi` — интерфейс QML.
- `update_panel.sh` — сборка и установка локального проекта на Ubuntu 24.04.

[Инструкция по развёртыванию на Ubuntu 24.04](docs/deployment-ubuntu-24.04.md).

На панели под обычным пользователем рабочего стола:

```bash
git clone --branch main https://github.com/dmpetr12/Lukoil.git ~/Lukoil
cd ~/Lukoil
bash update_panel.sh
```

После публикации новой версии в Git обновление панели:

```bash
cd ~/Lukoil
bash update_panel.sh --pull
```

Репозиторий: https://github.com/dmpetr12/Lukoil, основная ветка — `main`.
Скрипт использует upstream клонированной ветки.

Сначала прочитайте инструкцию: проверьте RS-485, параметры шкафа и остановите
старый проект. Рабочие настройки установленной версии находятся в
`~/Lukoil-runtime`, исходные файлы настроек используются только для начального заполнения.
